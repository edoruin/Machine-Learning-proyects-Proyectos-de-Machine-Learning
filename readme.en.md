## 🚀 Projects

### 1. [Salary Prediction](./Prediccion%20de%20Salarios/Predicción%20de%20Salarios%20.R)

In this project, a **Multiple Linear Regression** model was developed in R to predict employee salaries in a fictitious company, using **age** and **years of experience** as predictor variables.

#### Analysis performed:
- **Variable Relationship:** Correlation analysis between predictors and the target variable.
- **Multicollinearity:** Evaluation of the relationship between independent variables to ensure model stability.
- **Performance Metrics:** Use of **RMSE** and **R²** to evaluate the model's accuracy and explanatory power.

#### 🛠️ Requirements
- R and RStudio.
- Libraries: `ggplot2`, `dplyr` (included in the script).

---

### 2. [Binary Prediction with a Rainfall Dataset](./Binary%20Prediction%20Competition.ipynb)

This project corresponds to my participation in a **Kaggle** competition focused on climate inference. The goal is to predict the probability of rain using a historical dataset.

#### Highlights:
- **Feature Selection:** Use of filtering techniques and importance analysis.
- **Advanced Algorithms:** Implementation of boosting models such as **XGBoost** and **CatBoost**.
- **Optimization:** Hyperparameter tuning to maximize the AUC-ROC metric.

#### 🛠️ Requirements
- Python 3.x
- Jupyter Notebook / Kaggle Kernel.
- Libraries: `pandas`, `scikit-learn`, `xgboost`, `catboost`, `matplotlib`, `seaborn`.
